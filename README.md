# Premium Portfolio Website

A premium dark glassmorphic portfolio website built with React, Tailwind CSS, and Framer Motion.

## Features

- 🎨 **Dark Glassmorphic Design** - Modern frosted glass aesthetic with deep blacks and blue accents
- ✨ **Scroll Animations** - Smooth reveal animations powered by Framer Motion
- 🌟 **Hero Particles** - Interactive particle background on hero section
- 📱 **Fully Responsive** - Works beautifully on all devices
- ⚡ **Fast & Optimized** - Built with Vite for lightning-fast performance
- 🎯 **Smooth Navigation** - Seamless scrolling between sections

## Tech Stack

- **React 18** - UI library
- **Tailwind CSS 3** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **React TSParticles** - Particle effects
- **Lucide React** - Icon library
- **Vite** - Build tool

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Sections

1. **Hero** - Animated greeting with cycling role titles and particle background
2. **About** - Professional summary with expertise highlights
3. **Experience** - Work history timeline
4. **Projects** - Featured projects grid with hover effects
5. **Skills** - Technologies and certifications
6. **Education** - Academic background
7. **Contact** - Contact form and social links
8. **Footer** - Copyright and credits

## Customization

Edit the content in the component files under `src/components/` to personalize:

- Personal information
- Projects
- Skills
- Work experience
- Education
- Contact details
